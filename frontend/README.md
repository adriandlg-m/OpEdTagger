# OpEdTagger UI

La interfaz parte del ZIP 2 y consume el backend FastAPI local a través de `/api`.

Desde la raíz del proyecto, consulta `README.md`. Para desarrollo ejecuta `dev_windows.bat`; para crear el bundle de producción ejecuta `npm ci` y `npm run build` dentro de esta carpeta.

La interfaz está conservada en JSX/JavaScript en esta primera integración. Los contratos TypeScript se incorporarán progresivamente; no se afirma que la migración completa a TypeScript esté terminada.
